# Docs2Slides

Googleドキュメントに書かれたストーリーラインから、AIを活用してGoogleスライドのプレゼンテーションを自動生成するGoogle Apps Script Webアプリケーションです。

## 機能

- **テンプレート準拠**: 会社のスライドテンプレートをベースに、フォント・サイズ・色を維持したままテキストを置換
- **AI生成ボディ**: Gemini APIを使い、ドキュメントの指示に基づいてボディコンテンツ（箇条書き・テーブル・比較ボックス・プロセスフロー等）を自動生成
- **図表挿入**: スプレッドシートのチャートやGoogle Drive上の画像をスライドに直接挿入
- **チャート自動生成**: AIが提案したデータからチャートを一時スプレッドシートで生成し画像として挿入

## セットアップ

### 1. GASプロジェクトの作成

1. [Google Apps Script](https://script.google.com/) で新しいプロジェクトを作成
2. 本リポジトリの以下のファイルをプロジェクトに追加:
   - `Code.gs`
   - `DocumentParser.gs`
   - `SlideGenerator.gs`
   - `AIService.gs`
   - `ChartGenerator.gs`
   - `Index.html`
   - `Stylesheet.html`
   - `JavaScript.html`
3. `appsscript.json` の内容でマニフェストを更新（エディタ設定で「マニフェストファイルを表示」を有効化）

### 2. clasp を使う場合（推奨）

```bash
npm install -g @google/clasp
clasp login
clasp create --title "Docs2Slides" --type webapp
clasp push
```

### 3. Gemini API キーの取得

1. [Google AI Studio](https://aistudio.google.com/apikey) でAPIキーを作成
2. Webアプリの画面でAPIキーを入力

### 4. デプロイ

1. GASエディタで「デプロイ」→「新しいデプロイ」
2. 種類: 「ウェブアプリ」
3. 実行ユーザー: 「アクセスしているユーザー」
4. アクセス: 組織内のユーザー（またはご希望の設定）

## ドキュメントフォーマット

Googleドキュメントに以下のフォーマットでストーリーラインを記載してください。

### 基本構造

```
===スライド1===
タイトル: スライドのタイトル
メッセージ: キーメッセージ（1行）
ボディ:
ボディの内容や指示を記載

===スライド2===
タイトル: 次のスライドのタイトル
メッセージ: 次のキーメッセージ
ボディ:
ボディの内容
```

### 区切り文字

スライドの区切りは以下のいずれかが使えます:
- `===スライド1===`
- `---スライド1---`
- `##スライド1`

### アセット（図表・画像）の挿入

ボディ内に以下の記法で外部アセットを指定できます:

| 記法 | 説明 |
|------|------|
| `[図表: スプレッドシートURL]` | スプレッドシートのチャートまたはデータを挿入 |
| `[図表: URL#シート名!範囲]` | 特定のシート・セル範囲を指定 |
| `[画像: Google Drive URL]` | Google Drive上の画像を挿入 |
| `[チャート: URL]` | チャートを挿入（図表と同義） |

### 記述例

```
===スライド1===
タイトル: 売上報告 2024年第4四半期
メッセージ: 前年同期比120%の成長を達成
ボディ:
売上推移を棒グラフで表示してください。
主要な成長要因を箇条書きで3点まとめてください。

===スライド2===
タイトル: 地域別売上分析
メッセージ: 関東エリアが全体の45%を占める
ボディ:
地域別の売上割合を円グラフで表示してください。
[図表: https://docs.google.com/spreadsheets/d/xxxxx#Sheet1!A1:D10]

===スライド3===
タイトル: 今後の戦略
メッセージ: 3つの柱で持続的成長を実現
ボディ:
以下の3つの戦略を比較ボックスで表示してください：
1. 新規顧客開拓 - デジタルマーケティング強化
2. 既存顧客深耕 - クロスセル推進
3. 新サービス展開 - サブスクモデル導入
```

## テンプレートの要件

- スライドテンプレートの **1枚目** をベースレイアウトとして使用します
- テンプレート内のテキストボックスは位置に基づいて自動判定されます:
  - **最上部のテキストボックス** → タイトル
  - **2番目のテキストボックス** → メッセージ
  - **3番目のテキストボックス** → ボディ（AI生成コンテンツに置換）
- タイトル・メッセージのフォント、サイズ、色はテンプレートのスタイルが維持されます

## AI生成コンテンツの種類

ボディの指示内容に基づいて、AIが最適なレイアウト要素を選択します:

| 要素タイプ | 用途 |
|-----------|------|
| テキスト | 説明文、概要 |
| 箇条書き | 要点のリスト化 |
| テーブル | データの表形式表示 |
| チャート | グラフの自動生成（棒・折れ線・円・面） |
| 比較ボックス | Before/After、選択肢の比較 |
| プロセスフロー | 手順、ワークフローの視覚化 |

## ファイル構成

| ファイル | 説明 |
|---------|------|
| `Code.gs` | Webアプリのエントリーポイント、メイン処理 |
| `DocumentParser.gs` | Googleドキュメントのパース処理 |
| `SlideGenerator.gs` | スライド生成、テンプレート操作 |
| `AIService.gs` | Gemini API連携、コンテンツ生成 |
| `ChartGenerator.gs` | チャート・図表の生成 |
| `Index.html` | WebアプリのUI |
| `Stylesheet.html` | CSS |
| `JavaScript.html` | クライアントサイドJS |
| `appsscript.json` | GASマニフェスト |

## 必要な権限

- `documents.readonly` - Googleドキュメントの読み取り
- `presentations` - Googleスライドの作成・編集
- `drive` - ファイルのコピー、画像の取得
- `script.external_request` - Gemini API呼び出し
- `spreadsheets.readonly` - スプレッドシートからのデータ取得
